> [!fail] The Challenge: CLI & Permission Limits

> [!success] The Solution: Orchestration & Bypass
> - **Orchestrated Context**: We rewrote `orchestrator.py` to reference files by path rather than injecting content, bypassing CLI limits.
> - **The "System Override" Directive**: We implemented a `--permission-mode bypassPermissions` flag and injected a "HEADLESS MODE" system prompt. This forced the agent to bypass conversational pleasantries and execute file writes immediately, utilizing a specialized regex fallback to capture output even if the tool call failed.
